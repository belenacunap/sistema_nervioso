# Sistema nervioso · 2° medio · sitio estilo “Teorías de la evolución”

Versión estática lista para GitHub Pages. Mantiene el diseño, la estructura y las herramientas del sitio de referencia, adaptadas a los cuatro PowerPoint de Sistema Nervioso.

## Contenido

- Portada, OA, pregunta guía e hilo conductor.
- Cuatro clases completas: 29 pasos pedagógicos.
- Galería con las 72 diapositivas aportadas y los cuatro PPT originales.
- Actividades CER, profundización, errores frecuentes y comparador.
- Simulador visual del recorrido de una señal.
- Laboratorio 3D/VR y guía imprimible.
- Cuatro quizzes de 8 preguntas y simulacro de 20 preguntas.
- Ticket de salida, corrección, desglose, descarga y solicitud de envío por correo.
- Tema claro/oscuro, tamaño de letra, lectura por voz y pausa.

## Publicar en GitHub Pages

1. Cree un repositorio nuevo y suba **el contenido de esta carpeta** a la raíz.
2. En GitHub: Settings → Pages → Deploy from a branch.
3. Seleccione `main` y `/ (root)`.
4. Espere la publicación y abra la URL indicada por GitHub.

No se requiere compilación ni instalar dependencias. `index.html` es la portada.

## Activar el correo

El formulario usa FormSubmit, igual que el sitio de referencia. El destinatario principal es `belenacuna@liceosannicolas.cl`; se solicita copia a `franciscopinto@liceosannicolas.cl` y al correo ingresado por el estudiante.

La primera prueba genera un mensaje de activación en el correo principal. Belén debe abrirlo y confirmar el formulario. Después se debe realizar un segundo intento controlado y comprobar recepción en los tres buzones, incluida la carpeta de spam. La interfaz indica “solicitud de envío” porque la página no puede probar la entrega final de cada servidor de correo.

Si el establecimiento bloquea FormSubmit, conserve la descarga local del resultado y reemplace el formulario por un servicio institucional o una función de servidor. Nunca agregue claves privadas al JavaScript público de GitHub Pages.
